What it is

WebLens AI is a website quality analyzer built by Preet Mendpara. Paste a URL and a rule engine inspects the page, producing scored findings across SEO, accessibility, structure, links and performance.

A language model then explains those findings in plain language, prioritises them and suggests code fixes. The rule engine determines the score; the AI only interprets it, so the same HTML always gets the same score.

How scoring works

Each category starts at 100 and loses a fixed penalty per finding. The overall score is weighted: SEO 25%, accessibility 25%, structure 20%, links 15% and performance 15%. Every deducted point maps to a named finding.

Highlights

  • Deterministic, reproducible scoring with no model input
  • AI provider failover: Gemini, then Groq, then OpenAI
  • Analysis keeps working when no AI provider is reachable
  • SSRF-guarded fetching and server-side-only credentials
  • Report history stored in Supabase
