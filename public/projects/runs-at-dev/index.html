What it is

runs-at.dev is a free subdomain registry built by Preet Mendpara. Instead of a vercel.app or github.io address, developers get a distinctive yourname.runs-at.dev name for side projects, portfolios and demos.

Claiming a name writes one JSON file to an open GitHub repository. That file is the record: there is no hidden database, the history is the git log, and the rules are public code.

How it works

A wildcard DNS record points every subdomain at one Vercel project, so a newly claimed name resolves instantly with HTTPS and serves a profile card generated from the owner's GitHub account.

To use your own hosting, add a CNAME, A, TXT, MX or URL redirect record from the dashboard or by pull request. CI validates the change against a JSON Schema, and a GitHub Actions workflow pushes the record to DNS on merge.

Highlights
